# Climatología mensual 2015–2025

Bbox: 10.7,-75.4,11.6,-73.9

Cada mes = promedio de **todos los días** de ese mes en todos los años.
Ej.: enero = media de todos los 1–31 ene de 2015…2025.

## Entrada
- Diarios por año en `data/daily_YYYY/` (años: 2015–2025)

## Salida
- `climatology_2015_2025/sst_clim_MM.nc`, `chl_clim_MM.nc`
- stacks `*_monthly_climatology_2015_2025.nc`

Conservar para evaluaciones futuras.
